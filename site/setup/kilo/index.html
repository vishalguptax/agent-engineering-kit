Setup by tool

The best Kilo Code setup for clean, reviewed code

Set up Kilo Code to ship clean code: AGENTS.md rules, review subagents and workflow skills, from one npx command. Here is exactly what Kilo Code gets, the files that are written, and how to install it.

§01 · What Kilo Code gets

Kilo Code rules, skills, subagents, hooks and .env guard.

From the installer’s profile for Kilo Code, which follows its official docs (checked 2026-10-09). “Note” means it can’t be set safely from the project, so the installer tells you the exact step.

Kilo Code rules (AGENTS.md) yes

Reads the kit's block in AGENTS.md.

Kilo Code skills yes

Skills in .agents/skills (or a shared folder it also reads).

Kilo Code subagents yes

Agents in .kilo/agents (or a shared folder it also reads).

Kilo Code hooks: format on edit not supported

Kilo Code has no documented after-edit hook; use the pre-commit checks.

Keep Kilo Code out of .env note

Add "permission": { "read": { "*.env": "deny" } } to kilo.jsonc (the installer doesn't edit files with comments).

§02 · Files

What lands in your project.

Existing files are merged, never overwritten, and backed up first.

  • AGENTS.md: the rules block
  • .agents/skills/<name>/SKILL.md: the six skills (or a shared folder it also reads)
  • .kilo/agents/: the sub-agents, in its own format
  • .agent-kit/: the rulebook, format script, install record and backups

§03 · Install for Kilo Code

Preview it, then install.

This previews exactly what would change for Kilo Code and writes nothing. Run it again without --dry-run to install, or run npx agent-engineering-kit for the guided installer.

$ npx agent-engineering-kit --target . --tools kilo --dry-run

§04 · Day to day

Plan, build test-first, verify, simplify, review, ship.

Use the feature skill for anything beyond a small fix (/feature, or “use the feature skill” where there are no slash commands). It plans first, builds test-first, runs your real checks, simplifies, and reviews before calling anything done. The skills and the sub-agents in full.

§05 · Questions

Kilo Code setup questions.

What is the best Kilo Code setup?

Rules it reads every session, focused subagents for review, skills for the plan-build-verify-ship workflow, and guardrails that don't depend on the agent remembering. The Agent Engineering Kit installs each part in Kilo Code's own format where it can, and tells you the exact step where it can't.

Does Kilo Code read AGENTS.md?

Yes. Reads the kit's block in AGENTS.md.

Does Kilo Code support subagents?

Yes. Agents in .kilo/agents (or a shared folder it also reads).

How do I stop Kilo Code reading .env files?

Not from the project files: Add "permission": { "read": { "*.env": "deny" } } to kilo.jsonc (the installer doesn't edit files with comments).

Can Kilo Code format files automatically after each edit?

No. Kilo Code has no documented after-edit hook; use the pre-commit checks.
